int aa = 10;
int bb = 20;
Console.WriteLine($"Equation: {aa} + {bb} = {aa + bb:C}");

1- Why the output of this Equation = $30.00?
السبب:
•	الجزء {X + Y} يقوم بجمع الرقمين: 10 + 20 = 30.
•	النقطتان وحرف الـ C في {X + Y:C} يُسميان Currency Format Specifier (مُحدِّد تنسيق العملة).
•	يقوم هذا الحرف تلقائياً بتحويل الرقم إلى صيغة مالية وفقاً لإعدادات الجهاز (Culture):
1.	يضيف رمز العملة (في الإعداد الافتراضي مثل en-US يضيف $).
2.	يضيف خانتين عشريتين افتراضياً، ليصبح الناتج: $30.00
2- What is its benefit?
الفائدة:
•	عرض الأسعار بطريقة احترافية: توفير كتابة رموز العملات يدويًا مع الأرقام.
•	إدارة المنازل العشرية تلقائياً: وضع الفواصل العشرية (والفواصل بين الآلاف إن وُجدت) بشكل منسق.
•	دعم العملات المختلفة (Localization): إذا تم تغيير لغة/منطقة الجهاز أو البرنامج، سيتغير الرمز تلقائياً
 (مثلاً إلى EGP أو £ أو €) دون تعديل الكود نفسه.

3-Another example with a different specifier
سنستخدم مُحدِّد النسبة المئوية P (Percent Specifier)، وهو مفيد جدًا لحساب الخصومات والنسب:
int Test = 100;
Console.WriteLine(Test:P);
